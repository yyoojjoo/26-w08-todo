# 오늘의 할 일

오늘 해야 할 일을 기록하고 진행 상황을 관리하는 반응형 To-Do 웹 앱입니다. 할 일과 카테고리는 브라우저의 `localStorage`에 저장되므로 같은 브라우저에서 다시 열어도 유지됩니다.

## 주요 기능

- 할 일 추가: 텍스트를 입력하고 추가 버튼을 누르거나 Enter 키를 사용합니다.
- 등록일 지정: 새 할 일의 등록일을 직접 선택할 수 있습니다.
- 마감일 지정: 마감일은 선택 사항이며, 나중에 수정할 수 있습니다.
- 카테고리 관리: 카테고리를 직접 추가하고 할 일에 지정할 수 있습니다. 사용하지 않는 카테고리를 삭제할 수 있으며, 삭제한 카테고리가 할 일에 지정되어 있으면 해당 할 일의 카테고리만 해제됩니다.
- 상태 관리: 체크박스나 상태 버튼으로 대기, 진행 중, 완료 상태를 변경합니다. 완료된 할 일에는 취소선이 표시되고 축하 꽃가루 애니메이션이 실행됩니다.
- 목록 관리: 할 일의 내용과 날짜, 카테고리를 수정하거나 삭제할 수 있습니다. 삭제 전 확인 팝업이 표시됩니다.
- 상태 필터: 전체, 완료, 미완료, 대기 상태별로 할 일을 확인합니다.
- 날짜 검색: 목록의 날짜 검색 버튼을 눌러 월간 달력을 엽니다. 날짜별 등록일 및 마감일 일정을 확인하고 날짜를 선택해 해당 날짜의 할 일을 검색할 수 있습니다.
- 진행률: 완료한 할 일 수와 전체 대비 진행률을 표시합니다.
- 반응형 화면: 모바일에서도 사용할 수 있도록 구성했으며, 긴 할 일 내용은 화면 너비 안에서 줄바꿈됩니다.

## 기술 구성

- HTML, CSS, Vanilla JavaScript
- Tailwind CSS Play CDN
- 브라우저 `localStorage`

Tailwind CSS는 CDN을 통해 불러오므로 앱을 사용할 때 인터넷 연결이 필요합니다.

## 실행 방법

저장소 폴더에서 정적 웹 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다. 서버 실행 없이 `index.html`을 직접 열 수도 있지만, 로컬 웹 서버 사용을 권장합니다.

## 파일 구성

- `index.html`: 앱 화면과 Tailwind CDN 연결
- `style.css`: 보조 스타일과 애니메이션
- `script.js`: 할 일, 카테고리, 날짜 검색 및 저장 처리

## 데이터 저장 안내

데이터는 서버가 아닌 현재 브라우저의 `localStorage`에 저장됩니다. 따라서 다른 브라우저나 기기와 자동 동기화되지 않습니다. 브라우저의 사이트 데이터나 저장 공간을 삭제하면 저장된 할 일과 카테고리도 삭제될 수 있습니다.

## GitHub Pages 배포

저장소의 **Settings → Pages**에서 배포할 브랜치와 폴더를 선택해 GitHub Pages를 활성화하세요. 배포가 완료되면 같은 화면에 표시되는 사이트 주소로 앱을 열 수 있습니다. 이 README에는 아직 배포 주소가 설정되어 있지 않습니다.

## Tailwind 버전 안내

이 저장소는 PRD를 바탕으로 만든 Tailwind CSS 버전입니다. Tailwind는 HTML 요소에 유틸리티 클래스를 직접 조합해 스타일을 지정하고, 별도의 CSS 파일에는 CDN 유틸리티로 표현하기 어려운 달력 레이아웃과 애니메이션 등 보조 스타일을 작성했습니다. Bootstrap 비교 버전이나 배포 결과는 이 저장소에 포함되어 있지 않습니다.
