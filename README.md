# To-Do 리스트 — Tailwind 버전

오늘 할 일을 추가하고, 상태를 관리하며, 완료 진행률을 확인할 수 있는 반응형 To-Do 앱입니다. 목록과 선택한 필터는 브라우저의 `localStorage`에 자동 저장됩니다.

## 구현

- Vanilla JavaScript로 추가, 수정, 삭제, 상태 변경 및 필터 기능을 구현했습니다.
- Tailwind CSS Play CDN으로 화면을 구성하고, 추가 스타일은 `style.css`에 작성했습니다.
- 할 일 내용은 DOM의 `textContent`로 표시해 HTML 입력도 문자 그대로 렌더링합니다.

## 실행 방법

프로젝트 디렉터리에서 정적 웹 서버를 실행한 뒤 브라우저에서 엽니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 이동하세요. Tailwind CDN을 사용하므로 인터넷 연결이 필요합니다.

## 기능

- 입력 버튼 또는 Enter 키로 할 일 추가
- 체크박스 및 상태 버튼으로 대기 / 진행 중 / 완료 상태 변경
- 할 일 수정 및 삭제
- 할 일별 선택 마감 날짜 추가 및 수정
- 전체 / 완료 / 미완료 / 대기 필터
- 완료 개수와 진행률 표시
- 새로고침 후에도 데이터와 필터 유지
- 모바일 화면 대응 및 긴 텍스트 줄바꿈
